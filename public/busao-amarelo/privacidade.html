Política de privacidade

Busão Amarelo Publicação é uma ferramenta pessoal, usada apenas pelo dono do canal Busão Amarelo, na conta Google dele. Última atualização: 6 de novembro de 2026.

O que a ferramenta acessa

  • Pela API do YouTube: enviar vídeos ao canal do próprio dono, mudar título, descrição e privacidade desses vídeos e ler a lista de vídeos do canal.
  • Pela API do YouTube Analytics: ler os números do próprio canal (visualizações, horas assistidas, inscritos).

Como os dados são usados e guardados

  • Os dados servem só para publicar e acompanhar os vídeos do próprio canal.
  • A autorização da conta fica guardada apenas no servidor do dono, fora de qualquer repositório público, e nunca é compartilhada.
  • Nenhum dado é vendido, cedido a terceiros ou usado para publicidade.
  • Nenhum dado de outras pessoas é coletado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
